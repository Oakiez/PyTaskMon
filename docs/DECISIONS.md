# DECISIONS — บันทึกข้อตกลงของทีม

> ใช้เป็นวาระประชุม data contract (ประมาณ 1 ชั่วโมง) และเป็นบันทึกว่าตกลงอะไรไปแล้ว
> เมื่อตกลงแล้วให้เปลี่ยนสถานะเป็น ✅ พร้อมวันที่ และอัปเดต `contract.py` ถ้าเกี่ยวข้อง
> ทุกคนที่แก้ไฟล์นี้ให้เปิดผ่าน Pull Request

สถานะ: ⏳ รอตัดสินใจ | ✅ ตกลงแล้ว

## วาระประชุม

1. ทบทวน `contract.py` ทีละ field (10 นาที)
2. ตัดสินสูตร CPU% (10 นาที)
3. ตัดสิน priority mapping ทั้งสอง OS (10 นาที)
4. ตัดสินโครงไฟล์ `actions` (5 นาที)
5. ตกลงเรื่อง CI และคนรวม PR สุดท้าย (10 นาที)
6. นัดจุดส่งมอบข้อมูลระหว่างกัน (โชกุน → พีช) (10 นาที)

## D1. สูตร CPU%  ⏳

| ตัวเลือก | รายละเอียด |
|---|---|
| A (ข้อเสนอ) | หารด้วยจำนวน logical core เพดาน 100% เหมือน Task Manager ของ Windows |
| B | ไม่หาร เกิน 100% ได้ เหมือน `top` ของ macOS |

**ข้อเสนอ:** A เพราะเทียบ Windows กับ macOS ได้ตรงกว่า
**ผลกระทบ:** `collector.py` (โอ๊ค), หัวกราฟและหน่วยใน UI (โชกุน), ส่วนอธิบายในรายงาน (พีช)
**ที่ต้องแก้ถ้าเปลี่ยน:** ค่า `CPU_PERCENT_NORMALIZED_BY_CORES` ใน `contract.py`
**มติ:** _(ยังไม่ตัดสิน)_

## D2. Priority mapping  ⏳

| ระดับนามธรรม | Windows (Priority Class) | macOS (nice) |
|---|---|---|
| `low` | IDLE | 19 |
| `below_normal` | BELOW_NORMAL | 10 |
| `normal` | NORMAL | 0 |
| `above_normal` | ABOVE_NORMAL | -5 |
| `high` | HIGH | -10 |

**ข้อเสนอ:** ตามตาราง ไม่ใช้ REALTIME (เสี่ยงทำเครื่องค้าง)
**ข้อควรรู้:** บน macOS การลดค่า nice (เพิ่ม priority) ต้องใช้สิทธิ์ root → ถ้าไม่มีสิทธิ์ให้คืน `access_denied` พร้อมข้อความอธิบาย ไม่ต้องรัน dashboard ด้วย `sudo`
**ผลกระทบ:** `actions_windows.py` (พีช), `actions_unix.py` (โชกุน), การแปลงค่ากลับใน `collector.py` (โอ๊ค)
**มติ:** _(ยังไม่ตัดสิน)_

## D3. แยกไฟล์ actions  ⏳

| ตัวเลือก | รายละเอียด |

## D4. Field `priority` แยกจาก `nice_or_priority`  ⏳

- `priority`: ค่านามธรรม ที่ UI ใช้
- `nice_or_priority`: ค่าดิบของ OS ไว้ debug และใช้ในรายงานเปรียบเทียบ

ต่างจากเอกสาร handover ต้นฉบับที่มี field เดียว
**มติ:** _(ยังไม่ตัดสิน)_

## D6. CI (GitHub Actions)  ⏳

รัน `pytest` บน `windows-latest` และ `macos-latest` ทุก PR
**ข้อดี:** จับบั๊กข้าม OS ได้เอง **ข้อเสีย:** ใช้เวลาตั้งค่า และเทสที่ใช้ process จริงอาจไม่เสถียรบน runner
**มติ:** _(ยังไม่ตัดสิน)_
